Este é o módulo de geração, não a prévia estática. A v0.8.1 continua sendo o editor de preparação. Aqui o objetivo é solicitar um MP4 animado real a um modelo externo e verificá-lo. Sem serviço de inferência, não existe render. O módulo não transforma PNG rígida em dança.

01 · Conexão segura

Os motores são coordenados por um gateway Python local. Ele mantém a chave no ambiente do computador, nunca no HTML ou no GitHub Pages. Nenhum job começa automaticamente.

Para habilitar a geração, o gateway deve estar executando localmente em http://127.0.0.1:8765. Um site público estático não pode proteger sua chave de API.

02 · Seleção inteligente de motores

Padrão: o Furuya recomenda automaticamente o motor mais adequado para substituir personagens em vídeos virais existentes. Os motores anteriores continuam disponíveis no modo avançado. Recomendação não significa que a GPU esteja conectada ou que exista geração real.

Para múltiplas pessoas: Abrir o planejador multipersonagem (até 4 alvos), atribuir uma personagem a cada pessoa e exportar o plano. Essa etapa não é renderização.

03 · Arquivos de vídeo e personagem

Use sempre a referência original da personagem. O fluxo Video Remix usa imagem e movimento, mas não garante substituição localizada em multidão. Wan2.2 Replace exige pré-processamento oficial completo e uma GPU apta. Wan-Animate-2 recria o movimento e possivelmente o cenário.

04 · Gerar vídeo real (apenas motor com backend validado)

Custo anunciado no Viggle: 1 crédito por segundo de Remix; o resultado pode usar créditos gratuitos existentes. O saldo não diferencia créditos gratuitos dos comprados. Não há compra automática. O envio transfere seu vídeo/imagem ao provedor.

05 · Resultado generativo

Baixar MP4 realmente gerado

A existência do MP4 é apenas uma prova de renderização, não de fidelidade. Verifique identidade, anatomia, roupas, acessórios, coreografia, fundo e consistência temporal antes de aprovar o teste.

Motor GPU próprio: o Furuya agora possui uma ponte local para workflows ComfyUI já instalados, sem API proprietária. Ela requer exportação API do workflow, pesos e GPU adequados. Ver instruções e condições da ponte ComfyUI. O botão de geração nesta tela ainda não controla essa ponte diretamente.
