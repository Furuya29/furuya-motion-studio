GERAÇÃO TEMPORAL · P0 ALBEDO · PROTÓTIPO EXPERIMENTAL

Este é o módulo de geração, não a prévia estática. A v0.8.1 continua sendo o editor de preparação. Aqui o objetivo é solicitar um MP4 animado real a um modelo externo e verificá-lo. Sem serviço de inferência, não existe render. O módulo não transforma PNG rígida em dança.

01 · Conexão segura

O motor Viggle Video Remix é chamado por um gateway Python local. Ele mantém a chave no ambiente do computador, nunca no HTML ou no GitHub Pages. Nenhum job começa automaticamente.

Para habilitar a geração, o gateway deve estar executando localmente em http://127.0.0.1:8765. Um site público estático não pode proteger sua chave de API.

Verificando disponibilidade local…

02 · Teste Albedo: arquivos originais

Este fluxo Video Remix usa a imagem canônica e a coreografia do vídeo. Não usa máscara MediaPipe, face swap, nem substitui a referência original por ilustração gerada. O resultado preservará o fundo apenas na medida em que o provedor conseguir.

03 · Gerar vídeo real

Custo anunciado no Viggle: 1 crédito por segundo de Remix; o resultado pode usar créditos gratuitos existentes. O saldo não diferencia créditos gratuitos dos comprados. Não há compra automática. O envio transfere seu vídeo/imagem ao provedor.

Aguardando preparação. Nenhum render foi iniciado.
