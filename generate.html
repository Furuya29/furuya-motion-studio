Este é o módulo de geração, não a prévia estática. A v0.8.1 continua sendo o editor de preparação. Aqui o objetivo é solicitar um MP4 animado real a um modelo externo e verificá-lo. Sem serviço de inferência, não existe render. O módulo não transforma PNG rígida em dança.

01 · Conexão segura

Os motores são coordenados por um gateway Python local. Ele mantém a chave no ambiente do computador, nunca no HTML ou no GitHub Pages. Nenhum job começa automaticamente.

Para habilitar a geração, o gateway deve estar executando localmente em http://127.0.0.1:8765. Um site público estático não pode proteger sua chave de API.

03 · Arquivos de vídeo e personagem

Use sempre a referência original da personagem. O fluxo Video Remix usa imagem e movimento, mas não garante substituição localizada em multidão. Wan2.2 Replace exige pré-processamento oficial completo e uma GPU apta. Wan-Animate-2 recria o movimento e possivelmente o cenário.
